# ADR-0005：插件契约与架构治理

- 状态：已接受
- 日期：2026-08-11

## 决策

插件体系使用三个明确程序集身份：跨平台 `JayTom.Dws.Plugin.Contracts`、WPF `JayTom.Dws.Plugin.Presentation` 和平台实现 `JayTom.Dws.DeviceAdapters`。插件清单在加载前校验宿主最低版本和契约主版本。

项目引用、目标框架、禁止包、程序集身份、编译所有权和供应商 SDK 隔离由自动测试保护；新增代码由质量守卫检查。

## 结果

插件作者只需面向稳定契约，WPF 与设备能力可独立演进。不兼容清单会返回明确状态，而不是在运行期以类型加载异常失败。
